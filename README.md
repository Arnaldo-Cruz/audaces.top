# AUDACES — site institucional

Site estático pronto para hospedar no GitHub Pages.

## Arquivos
- `index.html` — página principal
- `style.css` — aparência e responsividade
- `script.js` — menu mobile, animações e aviso do formulário
- `assets/` — imagens e marca

## Como publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Faça upload de **todo o conteúdo desta pasta**, mantendo `assets/`.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Clique em **Save**.
7. Aguarde alguns minutos; o GitHub exibirá o endereço público.

## Antes da versão definitiva
O formulário de contato é apenas demonstrativo. Para receber mensagens de verdade, conecte-o a Formspree, Netlify Forms, EmailJS ou a um backend próprio.

Também é recomendável substituir os textos genéricos de notícias/projetos, inserir os contatos oficiais e conferir os links das redes sociais.
